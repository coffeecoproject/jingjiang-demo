# 镜匠 · 视频 Agent 工作台（原型演示）

给 AI 视频团队用的工作台原型：一句话下单，Agent 拆成镜头任务、调用模型生成、自动质检和返工，只在需要人判断时停下来。

- 在线原型：https://coffeecoproject.github.io/jingjiang-demo/
- 自动演示：https://coffeecoproject.github.io/jingjiang-demo/?demo=1
- 带讲解字幕的自动演示：https://coffeecoproject.github.io/jingjiang-demo/?demo=1&captions=1
- 介绍视频（2 分 20 秒，带旁白）：https://coffeecoproject.github.io/jingjiang-demo/jingjiang-intro.mp4

`index.html` 是离线单文件，下载后双击也能打开。

> 原型阶段：商单、人物、模型结果和成本都是示例数据，画面是插画占位，不接真实模型。旁白由微软在线语音合成。
